# AI development records

`session.md` and `engineering-notes.md` are records recovered from the earlier project copy. `recovery-session.md` contains actual copied excerpts from the resumed conversation and clearly labelled new engineering notes. `recovery-tests.txt` is captured test output, not a simulated benchmark.

These are partial records, not a complete exported conversation. Private tool payloads containing challenge data are excluded. Append a genuine export of any later AI work when available; never invent missing turns, tests or model results.

`final-work-session.md` records the final Work continuation; `final-tests.txt` contains its captured 62-test output. Historical logs and reports describe earlier checkpoints, not current scores.
